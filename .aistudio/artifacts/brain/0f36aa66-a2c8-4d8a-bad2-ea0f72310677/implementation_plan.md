# خطة تنفيذ التصميم الجديد لقسم الكاشير (POS) ونافذة الفاتورة الذكية

## 1. الملخص التنفيذي (Executive Summary)
بناءً على التفضيلات المحددة، سنقوم بإعادة هندسة وتصميم قسم الكاشير (POS) وشاشة معاينة وطباعة الفواتير بشكل جذري لتقديم واجهة عالمية استثنائية:
- **النمط البصري**: تصميم داكن فخم (Luxury Dark Glassmorphism) مع لمسات نيون ذهبية وزمردية هادئة، تباين عالي للأرقام والأسعار، وبطاقات زجاجية ثلاثية الأبعاد بحدود مضيئة ناعمة.
- **تخطيط الكاشير (POS)**: تقسيم الشاشة إلى بنية متجاوبة ذكية (شريط أدوات علوي مدمج + منطقة اختيار المنتجات والخلطات + سلة المبيعات والحسابات السريعة + حاسبة العروض والخصومات الذكية).
- **نافذة الفاتورة المنبثقة الذكية (Adaptive Modal)**: نافذة معلقة متكيفة تدعم التبديل السلس بين عروض الورق الحراري (80mm / 58mm)، مع توليد فوري للباركود ورمز QR الرقمي، وخيارات المشاركة والتخصيص الفوري.
- **عزل الطباعة التام (Strict Print Isolation)**: تطبيق آلية طباعة مخصصة تعتمد على iframe معزول وقواعد `@media print` صارمة تضمن طباعة الفاتورة وحدها وبأبعاد الطابعة الحرارية بدقة تامة دون طباعة أي جزء من واجهة التطبيق.

## 2. التغييرات المعمارية والمكونات (Architecture & Component Changes)

### أ. تحديث شاشة الكاشير الرئيسية (`components/POS.tsx`)
- **لوحة الكاشير الزجاجية الداكنة**:
  - شريط معلومات المورد والموظف والوردية بتأثير الزجاج البلوري الداكن (`backdrop-blur-xl bg-slate-900/80 border-slate-700/60`).
  - أزرار سريعة للوصول إلى: حاسبة العروض والخصومات (Promotional Bundles)، الخلطات الذكية، استعلام المخزون، والوردية.
  - بطاقات الأصناف والخلطات بأسلوب عصري جذاب يعرض نسبة توفر الزيوت، سعة الزجاجة، والسعر بخط عريض وواضح مع تأثيرات hover سلسة.
  - سلة المشتريات التفاعلية: تفاصيل كميات الزجاجات والغرامات والخصومات المطبقة مع مؤشر الأمان المالي والأرباح (حسب صلاحيات المستخدم).
  - لوحة إتمام الدفع السريع: أزرار كاش، بطاقة، دفع مركب، مع أزرار اختصار الأوراق النقدية السريعة (50، 100، 200).

### ب. إعادة بناء نافذة الفاتورة السريعة والمعاينة (`components/ReceiptModal.tsx`)
- **نمط الفاتورة الحرارية المتطورة (Thermal Modern 80mm/58mm)**:
  - ترويسة المتجر الأنيقة مع الشعار ورقم السجل والضريبة.
  - شريط الحالة والوقت النسبي ورقم الفاتورة ونوع الدفع.
  - جدول تفصيلي للمنتجات: اسم العطر / الخلطة، الحجم، عدد الغرامات، الكمية، الإجمالي، مع تمييز مبالغ الخصومات والتوفير باللون الأخضر.
  - ملخص الحساب الصافي، الضريبة، وقسم توفير العميل الإجمالي.
  - كود الاستجابة السريعة (QR Code) المتوافق مع الفوترة الإلكترونية + باركود رقم الفاتورة.
  - رسالة التذييل وسياسة الاستبدال بروح عصرية.
- **محطة تحكم ذكية جانبية بالفاتورة**:
  - زر الطباعة الحرارية السريعة الفورية.
  - خيارات تغيير عرض الورق (80mm أو 58mm) بضغطة زر.
  - أزرار سريعة لإرسال الفاتورة عبر واتساب، النسخ، والمشاركة الرقمية.
  - أداة ضبط الخط والمسافات والحدود في معاينة حية بدون مغادرة النافذة.

### ج. هندسة عزل الطباعة (`services/thermalPrintService.ts` و CSS)
- ضمان عدم تسرب أي خلفيات أو عناصر من واجهة الكاشير إلى أمر الطباعة (`window.print()`).
- بناء مسار طباعة دقيق عبر:
  1. إنشاء Hidden Sandboxed Iframe مخصص فقط لعنصر الفاتورة مع حقن تنسيقات الطباعة الحرارية المحسنة.
  2. دعم الطابعات الحرارية عبر البلوتوث و RawBT.
  3. محددات CSS خاصة بالطباعة `@media print { body * { visibility: hidden; } #thermal-receipt-printable, #thermal-receipt-printable * { visibility: visible; } }`.

## 3. تدفق المستخدم وتجربة الاستخدام (User Flow & Interactions)
1. **البيع السريع**: يبحث الكاشير عن العطر أو الخلطة أو يمسح الباركود، فتضاف الزجاجة فوراً للسلة بتأثير صوتي وبصري أنيق.
2. **تطبيق العروض**: نقرة واحدة على "حاسبة العروض والخصومات" لتطبيق عرض الباقات، مع تحديث ملخص التوفير فوراً.
3. **الدفع وإنشاء الفاتورة**: اختيار وسيلة الدفع (نقداً / شبكة)، والضغط على "إتمام البيع وطباعة الفاتورة".
4. **المعاينة الذكية والطباعة**:
   - تنبثق النافذة الذكية المتكيفة لعرض الفاتورة الحرارية طبق الأصل.
   - الضغط على "طباعة الفاتورة" يرسل الأمر مباشرة إلى الطابعة الحرارية وتخرج الفاتورة مطابقة تماماً لمقاس الورق المحدد دون أي أثر لباقي صفحة النظام.
   - إمكانية مشاركة الفاتورة عبر واتساب بنص منسق أو رابط في لحظات.

## 4. خطوات التحقق والاختبار (Verification & Testing Plan)
- **فحص التجميع والـ Lint**: فحص سلامة TypeScript ومطابقة الواجهات والأنماط وخلو الكود من أي أخطاء syntax.

- **اختبار عزل الطباعة**: تجربة عملية طباعة الفاتورة والتأكد 100% من أن ما يطبع هو الفاتورة فقط بدون عناصر الواجهة.
